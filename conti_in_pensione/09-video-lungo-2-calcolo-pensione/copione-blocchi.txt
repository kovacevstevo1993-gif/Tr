# Copione video lungo 2 - Conti in Pensione - "Quanto prenderai di pensione?" (numeri in lettere per la voce)

Titolo: Quanto prenderai di PENSIONE? I 3 numeri che decidono tutto

41 blocchi, 8069 caratteri (~9.6 min a 14 c/s). Un blocco = una voce CapCut = uno screenshot di fine blocco.


## HOOK

**BLOCCO 1**
```
Due colleghi. Stesso stipendio, stessi contributi. Uno va in pensione a sessantaquattro anni, l'altro a sessantasette. Secondo te, quanto cambia l'assegno ogni mese? Tieni a mente la tua risposta... perché alla fine facciamo il conto!
```

**BLOCCO 2**
```
E non è tutto! Oggi scopri anche il numero che quasi nessuno guarda sul proprio estratto conto... e perché un solo anno senza contributi può pesare sulla tua pensione ogni mese, per tutta la vita!
```

**BLOCCO 3**
```
Attenzione: quello che vedrai è un esempio semplificato, con numeri tondi. Serve a capire come ragiona il calcolo, non a dirti la tua pensione. La tua la scopri con i dati ufficiali... e ti spiego come!
```

**BLOCCO 4**
```
Partiamo da un errore che fanno quasi tutti: pensare che la pensione sia una percentuale dell'ultimo stipendio. Per tanti non è così! Dipende dal sistema di calcolo... e ce ne sono tre.
```


## I TRE SISTEMI

**BLOCCO 5**
```
Il primo si chiama retributivo: guarda le retribuzioni degli ultimi anni. Il secondo è il contributivo: conta tutto quello che hai versato, dal primo all'ultimo giorno. Il terzo è il misto: un po' dell'uno e un po' dell'altro.
```

**BLOCCO 6**
```
Quale vale per te? Dipende da una data: il trentuno dicembre millenovecentonovantacinque. Tre casi, tre porte. Scegli la tua!
```

**BLOCCO 7**
```
Porta numero uno: hai iniziato a versare contributi dal primo gennaio millenovecentonovantasei in poi. Per te vale solo il sistema contributivo, per tutta la carriera.
```

**BLOCCO 8**
```
Porta numero due: a fine millenovecentonovantacinque avevi meno di diciotto anni di contributi. Per te il misto: retributivo fino al millenovecentonovantacinque, contributivo da lì in poi.
```

**BLOCCO 9**
```
Porta numero tre: a quella data avevi almeno diciotto anni di contributi. Con la riforma Fornero, retributivo fino al duemilaundici, e contributivo dal primo gennaio duemiladodici.
```

**BLOCCO 10**
```
Hai visto? In tutte e tre le porte compare il contributivo! Capire come funziona serve a tutti... compreso te. E ora una domanda: su cento euro del tuo stipendio lordo, quanti vanno nel salvadanaio della pensione? Dieci? Venti? Trentatré?
```


## IL SALVADANAIO

**BLOCCO 11**
```
La risposta, per un lavoratore dipendente, è trentatré! L'Inps usa un'aliquota del trentatré per cento: su ogni cento euro lordi, trentatré entrano nel tuo montante contributivo. Sì, proprio come un salvadanaio!
```

**BLOCCO 12**
```
Facciamo un esempio. Bruno guadagna trentacinquemila euro lordi l'anno. Il trentatré per cento fa undicimilacinquecentocinquanta euro: ecco quanto entra nel suo salvadanaio ogni anno di lavoro!
```

**BLOCCO 13**
```
Se Bruno lavora quarant'anni con lo stesso stipendio, il salvadanaio arriva a quattrocentosessantaduemila euro. Per semplicità non conto la rivalutazione. Nella realtà il montante si rivaluta ogni anno, in base alla crescita media del Pil nominale degli ultimi cinque anni.
```

**BLOCCO 14**
```
Bene! Ma il salvadanaio non diventa pensione da solo. Serve un ultimo passaggio... ed è proprio il numero che quasi nessuno guarda! Si chiama coefficiente di trasformazione.
```

**BLOCCO 15**
```
Funziona così: moltiplichi il montante per il coefficiente, e ottieni la pensione di un anno. Il coefficiente cambia con l'età in cui vai in pensione, e il Ministero del Lavoro lo aggiorna ogni due anni.
```

**BLOCCO 16**
```
Per chi va in pensione nel duemilaventicinque e nel duemilaventisei, a sessantasette anni il coefficiente è cinque virgola seicentotto per cento. Quindi: quattrocentosessantaduemila euro per cinque virgola seicentotto per cento...
```

**BLOCCO 17**
```
...fa circa venticinquemilanovecentonove euro l'anno! Divisi per tredici mensilità: circa millenovecentonovantatré euro lordi al mese. Ecco la pensione di Bruno a sessantasette anni, nel nostro esempio!
```

**BLOCCO 18**
```
Attenzione: sono euro lordi, cioè prima delle tasse. Sul conto arriva il netto, e dipende dall'Irpef e dalla tua situazione. Per questo la cifra che vedi sul cedolino è più bassa!
```


## NUMERO UNO: L'ETÀ

**BLOCCO 19**
```
Ora il momento che aspettavi! Bruno, invece che a sessantasette, va in pensione a sessantaquattro anni, con lo stesso salvadanaio. Cambia solo il coefficiente: cinque virgola zero ottantotto per cento. Indovina di quanto scende la pensione?
```

**BLOCCO 20**
```
Quattrocentosessantaduemila euro per cinque virgola zero ottantotto per cento: circa ventitremilacinquecentosei euro l'anno. Cioè circa milleottocentotto euro lordi al mese.
```

**BLOCCO 21**
```
Sono circa centottantacinque euro lordi in meno, ogni mese, per tutta la vita! Per uscire tre anni prima. In pratica, ogni anno di anticipo costa più di sessanta euro al mese.
```

**BLOCCO 22**
```
Attenzione: nella realtà, chi esce prima ha anche meno anni di contributi. Quindi la differenza di solito è ancora più grande! Il nostro esempio tiene il salvadanaio uguale, per far vedere solo l'effetto dell'età.
```

**BLOCCO 23**
```
Questo è il numero uno che decide la tua pensione: l'età in cui esci. E il numero tre... è quello che costa di più, e quasi nessuno ci pensa! Ci arriviamo tra poco. Prima, il numero due.
```


## NUMERO DUE: QUANTO GUADAGNI

**BLOCCO 24**
```
Numero due: quanto guadagni. Ecco Anna, Bruno e Carla. Stesso percorso: quarant'anni di contributi, uscita a sessantasette anni. Anna guadagna venticinquemila euro lordi l'anno, Bruno trentacinquemila, Carla cinquantamila.
```

**BLOCCO 25**
```
Risultati, nel nostro esempio: Anna circa millequattrocentoventiquattro euro lordi al mese. Bruno millenovecentonovantatré. Carla circa duemilaottocentoquarantasette. Più guadagni, più il salvadanaio si riempie!
```

**BLOCCO 26**
```
Hai notato? In tutti e tre i casi la pensione è circa il settantaquattro per cento dello stipendio! Ma attenzione: è il caso perfetto, con stipendio sempre uguale e nessun buco. E la vita vera non è così!
```


## NUMERO TRE: I BUCHI

**BLOCCO 27**
```
Ed ecco il numero tre, il più pericoloso: gli anni senza contributi. Un buco può nascere da lavoro non versato, da una dimenticanza dell'azienda, o da una carriera spezzata. Ed è quello che quasi nessuno controlla!
```

**BLOCCO 28**
```
Torniamo a Bruno. Un solo anno senza contributi significa non aggiungere undicimilacinquecentocinquanta euro al salvadanaio. A sessantasette anni, sono circa cinquanta euro lordi in meno, ogni mese!
```

**BLOCCO 29**
```
Cinquanta euro al mese sembrano pochi? Per tredici mensilità sono circa seicentocinquanta euro l'anno... ogni anno, per tutta la vita da pensionato! Ecco perché un buco non va mai ignorato.
```


## COME CONTROLLARE

**BLOCCO 30**
```
E allora come controlli il tuo salvadanaio? Con un controllo da cinque minuti. Entra su inps punto it con Spid, carta d'identità elettronica o carta nazionale dei servizi, e cerca il fascicolo previdenziale.
```

**BLOCCO 31**
```
Apri l'estratto conto contributivo: è l'elenco di tutti i tuoi contributi, anno per anno. Controlla due cose: che non manchino anni, e che le retribuzioni siano giuste. Per ogni riga, chiediti: questo anno c'è?
```

**BLOCCO 32**
```
Se trovi un buco o un errore, usa la funzione per segnalare l'anomalia. Poi porta buste paga e contratti a un patronato: ti possono aiutare a far correggere la tua posizione.
```

**BLOCCO 33**
```
Poi c'è Pensami, il simulatore dell'Inps: ti mostra una stima della pensione in base ai tuoi dati. Provalo con età di uscita diverse e guarda come cambia l'importo... è proprio quello che abbiamo fatto noi adesso!
```


## I TRE ERRORI

**BLOCCO 34**
```
Occhio a tre errori! Primo: fidarti di un calcolo trovato in rete, senza controllare i tuoi contributi. Secondo: decidere quando lasciare il lavoro prima di aver verificato l'estratto conto.
```

**BLOCCO 35**
```
E il terzo, il più comune: aspettare l'ultimo anno per guardare la propria posizione. Correggere un buco richiede tempo e documenti. Meglio guardarla oggi... mentre hai ancora tutto il tempo!
```


## RIEPILOGO

**BLOCCO 36**
```
Ricapitoliamo! Tre numeri decidono la tua pensione. Uno: l'età in cui esci, che sceglie il coefficiente. Due: quanto guadagni, che riempie il salvadanaio. Tre: quanti anni sono davvero coperti da contributi.
```

**BLOCCO 37**
```
E adesso la risposta alla domanda iniziale! Stesso stipendio, stessi contributi: uscire a sessantaquattro invece che a sessantasette costa, nel nostro esempio, circa centottantacinque euro lordi al mese. Ci avevi pensato?
```

**BLOCCO 38**
```
Ricorda: è un esempio semplificato, con numeri tondi. Nella realtà contano il tuo sistema di calcolo, la rivalutazione, la carriera e gli anni coperti. Per la tua cifra controlla inps punto it, oppure chiedi a un patronato.
```

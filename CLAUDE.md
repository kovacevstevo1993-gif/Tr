# CANALE "CONTI IN PENSIONE" (@ContiInPensione) - LEGGERE PRIMA DI FARE QUALSIASI COSA

1. PRIMA di ogni risposta, e di nuovo PRIMA di ogni consegna all'utente, leggere per intero `conti_in_pensione/REGOLE-FISSE.md` e applicarlo alla lettera, senza interpretazioni proprie.
2. Eseguire SOLO gli ordini dell'utente. Se una frase non è chiara: UNA domanda sola, PRIMA di fare qualsiasi cosa. Mai inventare, mai aggiungere cose non chieste.
3. Ogni istruzione o correzione dell'utente va scritta SUBITO in `conti_in_pensione/REGOLE-FISSE.md` (commit + push), senza duplicare regole già presenti: se esiste già, si corregge quella.
4. Risposte corte, una cosa alla volta, niente giustificazioni lunghe.
5. Testi: titolo, descrizione, tag, commento da fissare, ciascuno in un RIQUADRO SEPARATO (```) da copiare uno alla volta; le didascalie una per blocco, ciascuna nel suo riquadro. Titolo senza hashtag.
6. Slide/clip: controllo su TUTTI i fotogrammi, render in parallelo (4 alla volta), movimento lento che finisce bene, nomi file con prefisso (S4-blocco01.mp4...).
